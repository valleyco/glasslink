# Board profile: ESP32-2432S028R (CYD) — primary v1

| Item | Value |
|------|-------|
| MCU | ESP32-WROOM (classic), no PSRAM |
| Flash | 4 MB |
| Panel | ST7789 320×240 landscape (`swap_xy`, `mirror_x` on — not invaders’ mirrors-off + game H-flip) |
| SPI | MOSI **13**, SCLK **14**, CS **15**, DC **2**, RST **n/c (-1)**, BL **21** |
| Touch | not used in v1 |

Driver notes (from invaders bring-up): dual-USB CYD units are often **ST7789 not ILI9341**; RGB order, invert off; RGB565 **byteswap on SPI TX**.

Firmware: `components/board/src/cyd_display_spi.c` implements `hal_display.h`.
